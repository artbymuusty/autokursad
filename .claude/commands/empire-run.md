description: Process a request through the full Agentic Empire workflow
argument-hint: <request>
---
Run `.ai/bin/empire run "$ARGUMENTS"`.

This executes the complete lifecycle: classification, specialist analysis,
conflict detection, debate where warranted, Supreme Jury adjudication, roadmap
update, and — where implementation is required and the change is not
safety-critical — coding, testing, four-dimension review and final
adjudication.

Relay to the user: the decision ID and verdict, any runtime constraint the Jury
had applied to it (safety-critical downgrade, evidence downgrade), the branch if
one was created, and what is now required of them. Never present an ESCALATED
or BLOCKED outcome as success.
