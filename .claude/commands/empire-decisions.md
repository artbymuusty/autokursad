---
description: Inspect the Supreme Jury decision register
argument-hint: [DEC-nnn]
---
With no argument, run `.ai/bin/empire decisions` and summarise the register:
how many decisions, how many active, which are safety-critical, which are
superseded.

With a `DEC-nnn` argument, run `.ai/bin/empire decisions DEC-nnn` and present
the record: question, verdict, confidence, rationale, acceptance criteria, and
any conflicts it resolved. If the decision was superseded, say so and name what
superseded it.
